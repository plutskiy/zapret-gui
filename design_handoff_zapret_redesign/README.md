# Handoff: Zapret GUI — новый интерфейс

## Overview
Редизайн десктопного приложения Zapret GUI (репозиторий plutskiy/zapret-gui, egui/Rust): главная с кнопкой питания и автоподбором конфигурации, список конфигураций с результатами теста, Telegram-прокси, настройки (общие, тестирование, свои списки сайтов). Тёмная тема, бирюзовый акцент, язык интерфейса: русский.

## About the Design Files
Файлы в этой папке — **дизайн-референсы в HTML**: прототипы внешнего вида, а не production-код. Задача: **воссоздать эти экраны в существующем коде приложения (egui) средствами его библиотек и паттернов**. Копировать HTML нельзя.
- `Zapret Redesign.dc.html` — обзорный холст со всеми экранами и вариантами.
- `Zapret Window.dc.html` — один параметризованный экран (props: `screen` = home | telegram | settings | sites; `state` = off | working | on | error; `hero` = ring | glow | orbit; `layout` = narrow | wide). Вся логика состояний — в классе внизу файла.
- Компоненты UI взяты из Celimos Design System (`_ds/…/`); токены — `tokens/colors.css`, `typography.css`, `elevation.css`.

Открыть: положите папку целиком (вместе с `_ds` из проекта и `support.js`) на статический сервер и откройте `Zapret Redesign.dc.html`. Без этого файлы читаются как исходный текст.

## Fidelity
**High-fidelity**: финальные цвета, шрифты, отступы и состояния. Воссоздавать с точностью до пикселя.

## Screens / Views
Окно: два формата. **Narrow 560×820** (как сейчас, вкладки-сегменты сверху) и **Wide 960×680** (боковая панель 208px). Общее: радиус окна 14px, фон `#060607`-ряд (`--bg-window`), заголовок окна 44px (светофор слева, «Zapret» по центру, Inter Tight 800 15px), нижняя строка «Журнал» 38px (фон `--ink-1000`, верхняя граница 1px `--line-soft`, текст JetBrains Mono 12px; цвет `--danger` при ошибке, иначе `--text-tertiary`).
Сверху окна — цветная «заливка» 420px высотой: `radial-gradient(ellipse 70% 100% at 32%(wide)/50%(narrow) 0%, rgba(акцент,0.14), transparent 70%)`; акцент — бирюзовый при подключении/подборе, красный (255,90,90) при ошибке, нет в состоянии «Отключено».

**Навигация**
- Narrow: SegmentedControl «Главная / Telegram / Настройки», по центру, отступ 4px 28px 12px.
- Wide: боковая панель 208px, фон `--bg-chrome`, правая граница `--line-soft`, padding 12px, пункты высотой 40px, радиус 10px, иконка 18px + текст 14px/500. Активный: фон `--teal-tint`, текст `--accent`, слева полоса 3px. Внизу карточка статуса: точка 8px (цвет тона, свечение при активности), заголовок 13px/600, имя конфигурации моно 12px.

## Interactions & Behavior
- Кнопка питания: off → клик запускает автоподбор (working) → при успехе on, иначе error. Во время working повторный клик отменяет; кнопка «Тест всех» disabled.
- Строка конфигурации: клик по play запускает её вручную; чекбоксы выбирают для теста.
- Переходы: 140–220ms `cubic-bezier(.4,0,.2,1)`; hover поднимает поверхность на один шаг `--ink`; фокус — кольцо 2px accent. В прототипе анимации не заложены (статичные макеты).
- Состояния ошибки: плашка предупреждения на главной, красный тон кольца и журнала.

## State Management
- `screen`: home | telegram | settings | sites
- `state`: off | working | on | error; `progress` (n/18) для working
- `configs[]`: {name, result: {ok, err, ping} | error, active, best, selected}
- `settings`: dataDir, autostartLast, parallel, timeout, siteTimeout, dpiBytes
- `telegram`: type (SOCKS5/MTProto), host, port, user, pass, autoOnZapret, autoOnApp; результат проверки (мс)
- `sites`: mode (обходить/исключения), domains[], dirty; результаты проверки, потоки
- Данные приходят из существующей логики приложения (src/app.rs, src/settings.rs).

## Design Tokens
Цвета: `#060607` окно, `#181820` карточка (`--surface-card`), `--ink-1000` поля/журнал, `--ink-700` чипы/дорожка, `--ink-500` неактивные точки, акцент `#00d9c0` (hover `#2ee9d2`, тёмный на акценте `#04201c`, `--teal-tint` фон активного, `--teal-glow`), danger `#ff5a5a`, warning `#fbbf24`-ряд (`--warning`), success `--success`. Текст: `#f4f5f7` при 100/66/42/26% (`--text-primary/secondary/tertiary`). Линии `--line`, `--line-soft`, `--line-strong`.
Шрифты: Inter Tight (заголовки, 700–800, tracking -0.02em), Inter (интерфейс 11–14px), JetBrains Mono (метаданные, пути, числа). Метки полей: 11px/600 uppercase +0.14em.
Радиусы: окно 14, карточки 16, контролы/строки 10–12, пилюли 999, чекбокс 5. Сетка 8px; padding страниц 28 (narrow) / 32 (wide).
Тени: окно `--shadow-xl`; диск `0 16px 40px rgba(0,0,0,.5)`; акцентное свечение `0 0 80px rgba(0,217,192,.28)`.
Egui: задать `Visuals` и `FontDefinitions` (встроить Inter Tight / Inter / JetBrains Mono как .ttf), радиусы через `Rounding`, кольцо и орбиту рисовать `Painter`-ом (circle_stroke, arc через path).
